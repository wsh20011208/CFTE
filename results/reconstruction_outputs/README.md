# Reconstruction Outputs

The reconstructed outputs of the supplementary dense GOP-4 experiment are distributed through the GitHub Release `v1.0.0-thesis`.

The release asset `codec_recon_gop4_fast.zip` contains 1,776 reconstructed MP4 files:

- 444 Single CFTE
- 444 NoRefine
- 444 FixedCMR
- 444 AdaptiveCMR oracle
