# Results

This directory contains the experimental results reported in the thesis.

- `gap3/` — four-method benchmark analysis for temporal gap 3
- `gap5/` — four-method benchmark analysis for temporal gap 5
- `gap7/` — four-method benchmark analysis for temporal gap 7
- `physical_bitstream/` — documentation and small result tables for the supplementary physical-bitstream experiment
- `reconstruction_outputs/` — documentation for the reconstructed MP4 outputs

Large binary archives, including physical bitstreams and reconstructed videos, are distributed through the GitHub Release `v1.0.0-thesis`.
